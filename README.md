# Website Our Printing Solo

Website statis (HTML/CSS/JS), tanpa instalasi, siap di-host di GitHub Pages.

## Yang perlu kamu edit
Buka `config.js`:
1. `wa`  -> nomor WhatsApp (format 62..., tanpa 0/+/spasi)
2. `waTampil` -> tampilan nomor di website
3. `harga` tiap produk (angka tanpa titik, contoh 15000)

## Struktur
- index.html  : isi halaman
- style.css   : tampilan & warna (ubah di bagian :root)
- config.js   : data toko, produk, harga, galeri
- script.js   : logika (tidak perlu diedit)
- assets/     : logo & foto

## Tes di komputer
Klik dua kali index.html (jalan di browser tanpa server).
